# Keelwater solution prototype

A clickable prototype of the claim lifecycle: a claimant submits a claim, then it's sorted by hand, in bulk, by rules in a workflow, with a claim sorting agent available as a side chat on every page (a placeholder for now). Plan and progress: [PLAN.md](PLAN.md).

**To open it:** download [`keelwater-prototype.html`](keelwater-prototype.html) and double-click it. It's one file of plain HTML, CSS and JavaScript, with no dependencies, no build step and no internet needed. To change it, edit that file and refresh the browser.

Deep links: `#consumer`, `#handler/inbox`, `#handler/bulk`, `#handler/workflow`, `#handler/agent`.

All claims, insurers and numbers in the prototype are **[INVENTED]**.

The look follows Radix (Radix Colors scales, Radix Themes-style components, Radix Icons) with Xelix brand tokens. The Barlow font is embedded at the end of the file.
